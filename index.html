    O que mudou no projeto

    Salvamento dos dados

    • As tarefas agora são salvas no navegador e continuam lá depois de recarregar a página.
    • O status de concluída também é salvo (método toJSON na classe Tarefa).
    • Funções separadas para salvar e carregar, com uma chave fixa no localStorage.
    • Se os dados salvos estiverem corrompidos, o carregamento não quebra mais a página.
    • O tema claro ou escuro escolhido também fica salvo.

    Novas funções

    • Prioridade alta, média ou baixa em cada tarefa, com etiqueta e barra colorida.
    • Abas Todas, Pendentes e Concluídas, cada uma com a sua contagem.
    • Painel de resumo com pendentes, concluídas, percentual e barra de progresso.
    • Botão para limpar todas as tarefas concluídas de uma vez.
    • Mensagens amigáveis quando uma aba está vazia.
    • Data de hoje embaixo do título.
    • Este botão com a lista de atualizações.

    Visual

    • Foto de perfil em formato redondo, com ícone de reserva se a imagem não existir.
    • Novas fontes, cores de prioridade e cartão com mais espaçamento.
    • Botão de concluir em formato de círculo, que se preenche ao marcar.
    • Layout ajustado para telas pequenas e animações reduzidas para quem prefere.

    Correções e melhorias no código

    • O salvarTarefas() estava fora da função e nunca era chamado.
    • Corrigido o maxlenght para maxlength no campo de texto.
    • Corrigido o erro de digitação no transition do CSS.
    • Cada tarefa ganhou um id próprio, então concluir e excluir funcionam com as abas filtradas.
    • O texto da tarefa é inserido com textContent, o que impede que HTML digitado quebre a página.
    • Os botões da lista usam um único ouvinte de clique, em vez de onclick dentro do HTML.
